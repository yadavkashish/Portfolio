# 💼 Kashish Yadav — Developer Portfolio

A modern, fully responsive developer portfolio website built using **Vite**, **React.js**, **Tailwind CSS**, and **Framer Motion**. Designed to showcase my skills, experience, projects, and contact information in a visually engaging manner.

## 🚀 Live Demo

[👉 View Portfolio]([https://your-live-site-link.com](https://kashishyadavportfolio.netlify.app/))

---

## 📌 Features

- ⚡️ Built with Vite for fast development and optimized builds
- 🎨 Beautiful, responsive UI with Tailwind CSS
- 🌙 Dark Mode toggle
- 📜 Typewriter effect in Hero section
- 🧩 Scroll-based animations with Framer Motion / AOS
- 🖼️ Custom Image Collage in About section
- 📚 Experience & Education timeline
- 💻 Projects with icons and tech stack
- ✉️ Contact form with interactive icons
- 🧠 Patent and project highlights

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, Framer Motion / AOS
- **Icons & Assets:** React Icons, Styled Components (if used)
- **Animations:** Framer Motion, CSS transitions
- **Deployment:** GitHub Pages / Vercel / Netlify

## 🧑‍💻 Getting Started

### Prerequisites

- Node.js ≥ 14
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/yadavkashish/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

---

## 📦 Build

To create an optimized production build:

```bash
npm run build
```

Then deploy the contents of the `dist` folder using your preferred service (Netlify, Vercel, GitHub Pages, etc.).
